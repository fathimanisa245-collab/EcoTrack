# 🌿 EcoTrack — Daily Eco-Habit Tracker

## About the Project

EcoTrack is a simple and interactive web application that encourages
people to build eco-friendly daily habits.

Users can complete sustainability challenges, earn eco-points,
track their daily progress and unlock achievement badges.

## Features

- Six daily eco-friendly challenges
- Points for completed tasks
- Daily progress bar and completion percentage
- Three achievement badges
- Rotating environmental tips
- Browser-based progress saving using localStorage
- Daily progress reset option
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Git
- GitHub

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.

No backend or database installation is required.

## Git Workflow Demonstration

The project uses Git for version control and GitHub for remote
repository hosting.

1. Initialize a local Git repository.
2. Commit the initial project files.
3. Create a feature branch.
4. Implement the achievement feature.
5. Commit the feature changes.
6. Merge the feature branch into main.
7. Push the changes to GitHub.
8. Deploy the website using GitHub Pages.

## Project Purpose

EcoTrack demonstrates how basic web technologies can be used to
create an interactive application that promotes sustainable habits.
